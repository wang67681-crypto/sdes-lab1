# S-DES 程序 开发手册（接口文档）

本文档说明各组件封装后对外提供的接口，供二次开发与维护使用。所有位串均以 `"0"/"1"` 字符串表示（下标从左到右为高位到低位），置换表下标为 1 起始。

## 1. 模块划分

| 模块 | 文件 | 职责 |
|---|---|---|
| 核心算法 | `SDES.java` | 置换/异或/S 盒等基础操作、密钥扩展、加解密、字符串模式 |
| 破解与分析 | `BruteForce.java` | 多线程暴力破解、密钥碰撞封闭测试 |
| 图形界面 | `SDESGUI.java` | Swing 界面与交互（调用 `SDES` / `BruteForce`） |
| 网络通信 | `SDESClient.java` / `SDESServer.java` | TCP Socket 加密通信演示 |

## 2. SDES 核心算法类接口

### 2.1 常量（置换表与 S 盒）

| 常量 | 类型 | 值 |
|---|---|---|
| `P10` | `int[]` | `{3,5,2,7,4,10,1,9,8,6}` |
| `P8` | `int[]` | `{6,3,7,4,8,5,10,9}` |
| `IP` | `int[]` | `{2,6,3,1,4,8,5,7}` |
| `IP_INV` | `int[]` | `{4,1,3,5,7,2,8,6}` |
| `EP` | `int[]` | `{4,1,2,3,2,3,4,1}` |
| `P4` | `int[]` | `{2,4,3,1}` |
| `S0` | `int[][]` | 教材标准 S-box1 |
| `S1` | `int[][]` | 课程自定义 S-box2：`{0,1,2,3},{2,3,1,0},{3,0,1,2},{2,1,0,3}` |

> 若要改用其它 S 盒或置换表，直接修改对应常量即可，其余代码无需改动。

### 2.2 位操作工具

#### `String permute(String bits, int[] table)`
- 说明：按置换表重排位串。
- 参数：`bits` 源位串；`table` 1 起始的位置索引。
- 返回：重排后的位串。
- 示例：`permute("1010000010", P10)` → `"1000001100"`。

#### `String leftShift(String bits, int n)`
- 说明：循环左移 `n` 位。
- 参数：`bits` 位串；`n` 左移位数。
- 返回：左移后的位串。
- 示例：`leftShift("10000", 1)` → `"00001"`。

#### `String xor(String a, String b)`
- 说明：逐位异或。
- 参数：两个等长位串。
- 返回：异或结果。

#### `String sbox(String fourBits, int[][] box)`
- 说明：S 盒查表，4 位输入 → 2 位输出。行 = 第 1、4 位，列 = 第 2、3 位。
- 参数：`fourBits` 4 位输入；`box` 4×4 S 盒。
- 返回：2 位结果。

### 2.3 轮函数

#### `String f(String right4, String key8)`
- 说明：轮函数 F，流程为 E/P 扩展 → 与子密钥异或 → S0/S1 → P4。
- 参数：`right4` 右半 4 位；`key8` 8 位子密钥。
- 返回：4 位输出。

#### `String fk(String left4, String right4, String key8)`
- 说明：轮函数 fk，`left4 XOR f(right4, key8)`。
- 参数：`left4`/`right4` 左右半各 4 位；`key8` 子密钥。
- 返回：新的左半 4 位。

### 2.4 密钥扩展

#### `String[] keyGen(String key10)`
- 说明：由 10 位密钥生成两个 8 位子密钥（P10 → LS-1/LS-2 → P8）。
- 参数：`key10` 10 位密钥。
- 返回：`String[2]`，`[0]` 为 K1，`[1]` 为 K2。
- 示例：`keyGen("1010000010")` → `{"10100100", "01000011"}`。

### 2.5 加解密

#### `String encrypt(String plain8, String key10)`
- 说明：加密一个 8 位分组。
- 参数：`plain8` 8 位明文；`key10` 10 位密钥。
- 返回：8 位密文。

#### `String decrypt(String cipher8, String key10)`
- 说明：解密一个 8 位分组（子密钥使用顺序与加密相反）。
- 参数：`cipher8` 8 位密文；`key10` 10 位密钥。
- 返回：8 位明文。

### 2.6 字节 / 字符串转换

#### `String byteToBits(int b)`
- 说明：字节值（0–255）→ 8 位二进制串。
- 参数：`b` 字节值（负数按 `& 0xFF` 处理）。
- 返回：8 位位串。

#### `int bitsToByte(String bits)`
- 说明：8 位二进制串 → 字节值。

#### `String keyFromInt(int k)`
- 说明：整数（0–1023）→ 10 位二进制密钥串，供暴力破解穷举用。

#### `String encryptString(String text, String key10)`
- 说明：字符串 → 逐字节加密 → 十六进制串（每字节两位）。
- 参数：`text` 明文（ASCII / 0–255 字符）；`key10` 10 位密钥。
- 返回：十六进制密文串。
- 示例：`encryptString("A", "1010000010")` → 两位十六进制。

#### `String decryptString(String hex, String key10)`
- 说明：十六进制串 → 逐字节解密 → 字符串。
- 参数：`hex` 偶数长度的十六进制串；`key10` 10 位密钥。
- 返回：明文串；若 `hex` 长度非偶数抛出 `IllegalArgumentException`。

## 3. BruteForce 类接口

#### `List<String> crack(String plain, String cipher, int threads)`
- 说明：多线程暴力破解，穷举全部 2^10 = 1024 个密钥。
- 参数：`plain` 8 位明文；`cipher` 8 位密文；`threads` 线程数（`<=0` 时按 1 处理）。
- 返回：所有满足 `encrypt(plain, key).equals(cipher)` 的密钥列表（可能多个）。

#### `String collisionAnalysis(String plain)`
- 说明：封闭测试分析。固定明文遍历全部密钥，统计各密文被多少密钥映射。
- 参数：`plain` 8 位明文。
- 返回：多行文字摘要（不同密文数、平均密钥数、最大碰撞数、结论）。

## 4. 网络通信模块

`SDESClient` / `SDESServer` 为演示程序，入口均为 `main`，无需作为库调用。二者共享密钥 `1010000010`、端口 `8888`（可在源码中修改）。协议为行文本：客户端发送一行十六进制密文，服务器回一行「服务器已解密：<明文>」。

## 5. 二次开发要点

1. **替换算法参数**：直接改 `SDES` 类顶部的 `P*` / `S*` 常量，不影响调用方。
2. **复用加解密**：新功能只需调用 `SDES.encrypt` / `SDES.decrypt`（单块）或 `SDES.encryptString` / `SDES.decryptString`（字符串），无需关心内部流程。
3. **复用破解/分析**：调用 `BruteForce.crack` / `BruteForce.collisionAnalysis`。
4. **扩展网络协议**：在现有 `SDESServer` 的读循环里追加命令分支即可。
