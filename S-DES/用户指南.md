# S-DES 加解密程序 用户指南

## 1. 软件简介

本程序用 Java 实现简化版 DES（S-DES）算法：分组长度 8 bit、密钥长度 10 bit，提供图形界面（Swing），支持单块加解密、ASCII 字符串加解密、暴力破解与封闭测试分析，并可将加解密应用到 TCP Socket 网络通信。

## 2. 运行环境

- 操作系统：Windows / Linux / macOS 均可
- 需要 JDK 8 及以上版本（开发与测试使用 JDK 25）

## 3. 编译

在项目目录下执行（源码含中文注释，需指定 UTF-8 编码）：

```bash
javac -encoding UTF-8 *.java
```

## 4. 图形界面使用

启动图形界面：

```bash
java SDESGUI
```

界面共有四个标签页。

### 4.1 单块加解密（第 1 关）

1. 在「10 bit 密钥 K」输入框填入 10 位二进制（如 `1010000010`）。
2. 在「8 bit 数据」输入框填入 8 位二进制明文（或密文）。
3. 点击「加密」得到密文，点击「解密」得到明文。
4. 下方会同时显示子密钥 K1、K2，便于核对密钥扩展结果。

### 4.2 字符串加解密（第 3 关）

1. 填入 10 bit 密钥。
2. 在文本区输入 ASCII 字符串（按 1 Byte 分组）。
3. 点击「加密字符串」：密文以十六进制显示（每字节两位）。
4. 把十六进制密文粘回输入区，点击「解密字符串」还原明文。

### 4.3 暴力破解（第 4 关）

1. 填入已知的 8 bit 明文、8 bit 密文。
2. 设置线程数（默认取 CPU 核数）。
3. 点击「开始暴力破解」：程序穷举全部 1024 个密钥，列出所有匹配密钥并显示耗时。

### 4.4 封闭测试分析（第 5 关）

1. 填入一个 8 bit 明文分组。
2. 点击「分析密钥碰撞」：统计 1024 个密钥映射到各密文的分布，给出碰撞结论。

## 5. 命令行自测

```bash
java SDES          # 核心算法自测：打印参考向量的密文、解密还原、K1/K2
java BruteForce    # 暴力破解 + 碰撞分析自测
```

## 6. TCP 网络通信演示（第 3 关扩展）

需要两个终端，双方共享同一密钥 `1010000010`：

```bash
# 终端 1：启动服务器（监听端口 8888）
java SDESServer

# 终端 2：启动客户端，发送明文（可替换成任意 ASCII 字符串）
java SDESClient "Hello S-DES"
```

- 客户端：把明文逐字节加密后，以十六进制密文发送给服务器。
- 服务器：接收密文、解密、打印明文，并把「服务器已解密：…」回显给客户端。

## 7. 输入格式与常见问题

| 问题 | 说明 |
|---|---|
| 密钥格式 | 必须恰好 10 位，只含 `0` / `1` |
| 数据格式 | 单块模式必须恰好 8 位，只含 `0` / `1` |
| 字符串模式 | 支持 ASCII / 0–255 字符；中文等超出单字节的字符不会被正确还原 |
| 密文格式（解密） | 十六进制串，长度须为偶数（每字节两位），如 `AF5AD42F` |
| 端口被占用 | 更换 `SDESServer.java` / `SDESClient.java` 里的 `port` 值后重新编译 |
